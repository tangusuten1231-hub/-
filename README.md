# 庭づくりアプリ 🌼

位置情報から **あなたの庭の気候** を調べ、宿根草ガーデンづくりを手助けする Web アプリ（PWA）です。
インストール不要・APIキー不要で、スマホのブラウザからそのまま使えます。

## できること

| 画面 | 内容 |
| --- | --- |
| 🏠 ホーム（今日の庭） | 案内役の小鳥「ツピ」（シジュウカラ）の季節のひとこと、今日の天気と注意、今月の作業、いま見頃の花、今月の楽しみをまとめて表示 |
| 🌍 場所と気候 | 現在地 or 地名検索 → 過去10年の気象データから **耐寒性ゾーン（USDA）・暑さゾーン（AHS）・終霜／初霜・熱帯夜・降水量・降雪量** を算出。地域ごとの栽培ポイント、月別の気温・降水グラフ、季節ごとの南中高度と「高さ2mの塀の影の長さ」も表示 |
| 🌼 図鑑 | **436種・926品種**（ガーデンデザイナーが自然風植栽で使うグラス・セリ科・プレーリーの植物、ガザニアなど南アフリカの植物、日本の野の花を含む。宿根草・一年草・グラス・ハーブ・薬用植物・低木・シダ・球根・野菜・ベランダ向きの草花や果樹）。別名・通称（漢字名・英名など）でも検索可能。名前・学名・科で検索、科・種類・花期・花色・用途（ドライフラワー・種取り・ハーブティー・草木染め・冬の枯れ姿など）で絞り込み、並べ替え（科ごと・花期順・草丈順・価格順）、一覧／カード表示。各植物に科・用途・豆知識（名前の由来・逸話・受賞歴など）。品種ごとに花色・草丈・開花期・耐寒性・耐暑性・蒸れへの強さ・葉色・価格が異なる場合は個別に収録。種ごとのカードで品種を切り替えて比較できる。写真（品種名で Wikimedia Commons を検索、なければ種の Wikipedia 写真）、花色・草丈・開花期・花の形・葉色・株間・平均価格・雰囲気タグを掲載。日当たり・湿り気・草丈・花色・開花月・雰囲気で絞り込み、地域の気候に対して **◎ よく育つ / ○ 工夫すれば育つ / △ 難しい** を理由付きで判定 |
| 🎨 プラン | 「白と青のナチュラルな庭、蝶が来る」など **言葉のイメージから植栽プランを自動生成**。気候・日当たり・花壇サイズに合わせて、開花リレー・高さの層（前景〜後景）・花の形のバランス・色の組み合わせを考えて植物を選び、**季節ごとに変化するイメージ図**・**配置図（1株ずつ）**・植物リスト・**概算費用**（苗代＋土づくり＋マルチ）を表示。予算との比較、別の案の生成、マイ庭への反映も可能 |
| 🏡 庭まるごとプラン | 敷地の形（**長方形・L字・方眼をタップして描く自由な多角形**）と大きさ（面積の指定も可）、家の方角から、**小道・テラス・パーゴラ・ベンチ・バードバス・小さな池・シンボルツリー・芝生・ハーブ菜園・堆肥置き場・石積み**を配置し、花壇ごとに植栽を自動生成。塀・家・木の影から花壇ごとの日当たりを判断。平面図に **園内の案内ルート** と **フォトスポット（撮る位置と向き）** を重ねて表示し、**季節の見どころ**・**園内の案内**・**フォトスポット（何を・いつ・どう撮るか）**・来そうな生き物・生物多様性度・構造物を含む概算費用をプレゼンテーション形式でまとめる。平面図は花壇の範囲を太線で示し、植物を群れ（ドリフト）で塗り分けて、番号札から植物の一覧へ移動できる。**植物の一覧（買い物メモのコピー付き）**・**つくる順番（下準備→構造物→木→宿根草→球根→一年草）**も表示 |
| 🪴 ベランダ・鉢植え | プランの「ベランダ・鉢」モード。幅・奥行き・向き（8方位）・階・手すりの種類と高さ・上の階のバルコニー・正面の建物・棚の段数と置き場所・手すり掛けを入力すると、場所の緯度と太陽の動き（夏至・春分秋分・冬至）から、手すり・屋根・両端の仕切り板の影を考えて **場所ごとの日照時間** を計算。断面図・日照グラフ・正面の配置図とともに、鉢ごとの植物・鉢の号数・用土の配合・重さ・費用、開花・収穫カレンダー、水やり、来る生き物、注意点（西日・照り返し・強風・避難経路・管理規約）をまとめる |
| 🏺 鉢植えガイド | 図鑑のすべての植物に「鉢植えにするなら」：おすすめの鉢の大きさ（号・直径・容量）と深さ、用土の配合（ドーナツグラフ）、水やり・肥料・植え替え、鉢植え向き度 |
| 🌹 コテージガーデン | 植栽スタイルに追加。花・ハーブ・こぼれ種の一年草をすき間なく混ぜ植え |
| 🧱 植栽での役割 | グラウンドカバー・縁取り・日陰の下草・フィラー・地模様・アクセント・骨格・目隠し・ハンギング向きを植物ごとに判定。図鑑で絞り込み、プランでは「足元をグラウンドカバーで覆う」や「縁取り」「目隠し」のキーワードに対応し、役割のバランスとアドバイスを表示 |
| 🍵 ハーブティー | 「楽しむ」の「ハーブティー」タブ。レシピ32種（庭の材料と市販の材料）、気分・用途（ほっとひと息・眠る前に・食後に・アイスティー向き・カフェインなし など）で絞り込み、「庭の材料で作れる」レシピと、庭の材料の摘みどき・乾かし方。図鑑の植物からも関連レシピへ |
| 📅 植え時 | 地域の霜の時期・暑さから、植物ごとの植え付け（と種まき）の適期を計算し、図鑑・ベランダの鉢・マイ庭に月のバーで表示（宿根草・一年草・球根・樹木・野菜それぞれの考え方、南半球にも対応） |
| 🖼 イメージ画像 | 植栽スタイルの選択はイメージ図つきのカードに。スタイルや原産地の風景は、無料のAIアプリの画像生成に頼む依頼文を作成でき、できた画像を登録して表示できる（画像は端末に保存。アプリからAIへの送信はしない） |
| 🗺 原産地 | 図鑑の「原産地」タブ。世界地図の模式図で15の地域を表示し、タップするとその土地生まれの植物の一覧と、風景のイラスト・解説（写真はWikipediaから取得できれば表示） |
| 🥕 野菜とポタジェ | トマト・ナス・キュウリ・レタス・ソラマメ・アスパラガス・ルバーブなど約30種の野菜（品種ではなく種類ごと）を収録し、収穫月・植え付け/種まき・収穫の作業を作業暦に表示。植栽スタイルに **ポタジェ**（区画に野菜、縁にハーブや花、中心にアクセント）を追加し、区画分けの配置図と収穫カレンダーを作成。庭まるごとプランの「キッチンガーデン」はポタジェ式で植栽 |
| ⭕ 花壇の形 | 花壇プランで **長方形・円形・楕円形・半円形・そら豆形・曲線ボーダー** を選べる。形の内側だけに植え、円・楕円は中央を高く、半円・曲線ボーダーは奥を高く配置。植栽図は曲線の輪郭で描き、植え付け手順に曲線の縁の引き方（杭とひも）を表示 |
| ⚖️ 保存した案の比較 | 花壇・庭まるごと・ベランダの案を保存し、2〜3件を並べて比較（図・種類・株数・費用・1㎡あたり・花の咲く月・冬も緑・蝶や蜂・手間いらず・共通の植物）。いちばん良い値を強調。名前の変更・開き直し・削除 |
| 📷 育ち具合の写真くらべ | マイ庭で「定点」（同じ場所・向きから撮る場所）を作り、記録の写真を定点ごとに並べる。前後2枚をスライダーで重ねて比べ、プランを反映した庭では写真の月の「プランどおりの姿」と並べて見比べられる |
| 🗓 庭づくりの段取り | 庭まるごとプランの「つくる順番」に予定月を付け、作業暦に登録。作業暦の月ごとにチェックでき、ホームの「今月の作業」にも表示（遅れている分も） |
| 🌿 デザイナー品質の庭まるごとプラン | 「曲線（自然風）／直線（整形式）」を選べる。自然風では花壇の縁がふくらみとくびれのある曲線になり、芝生に有機的な形の島花壇を1〜2つ配置。小道も曲線で描く。各花壇は実際の形（曲線の縁・角）に合わせて植栽を計算し、平面図に株の位置と育ったときの広がりを描く。先に決めた花壇のグラス・骨格・グラウンドカバーを他の花壇でもくり返して、庭全体に統一感を出す |
| 📐 デザイナーの視点 | 花壇・庭まるごとプランに、植え付け密度（株/㎡）、育ったときに地面を覆う割合、花のある月、冬も見どころがある植物の数、層の構成（骨格・季節の主役・地面を覆う）をスタイルごとの目安と比較、配色（類似色・補色など）、デザインの考え方（曲線・くり返し・群れ・季節の連続・見せ場・密度）を表示。植え付けの間隔は株張りの0.85倍（育つと触れ合う密度） |
| 👥 植え方の目安（群れの大きさ） | 全植物に「1株で目立たせる／2〜3株／3〜5株／7株以上／一面に敷きつめる」の目安を付け、図鑑とプランに表示。混ぜ植えのスタイルではこの大きさで群れをつくる |
| 🐝 庭の仲間 | 来客は日ごとに決まり、会った日数で「なかよし度」（はじめまして→顔なじみ→なかよし→親友）が上がる。話しかけるとひとこと、ときどき「おみやげ」（仲間の目線の庭づくりのコツ）を置いていく。なかよしになると「ひみつ」を教えてくれる。「楽しむ」に仲間アルバム（会えた仲間・なかよし度・おみやげのコレクション）。アゲハチョウのハネル、カタツムリのノンノが仲間入り。記録を書くと仲間がひとこと |
| 🎛 こだわり設定 | プラン作成時に「入れたい植物（必ず使う）」「避けたい植物」「花の色（中心に使う／この色だけ）」「葉の色」「植栽密度（ゆったり・標準・しっかり・密植）」「種類の数」「いちばん高い植物」「とくに咲かせたい月」「冬も楽しむ」を組み合わせて指定できる。花壇プランと庭まるごとプランに対応（入れたい植物は日当たりの合う花壇へ）。条件に合わない指定は注意を表示 |
| ✳️ 点・線・面の構成 | 新スタイル。形の強い植物を間をあけた「点」に、低い植物で手前の縁と花壇を斜めに横切るリボン状の「線」を、グラスやグラウンドカバーで残りを覆う「面」をつくる。全スタイル共通で、同じ高さ×同じ形の重なりを避け、葉色の変化も加えて多様な植物を選ぶ |
| 🖐 セミオート | 花壇プランで「自分で選ぶ」を選ぶと、役割と大きさに合わせた枠をアプリが用意し、枠ごとに候補（同じ日当たり・土・気候で育ち、同じ役割と近い大きさの植物。写真付き、「同じ形・同じ色・同じ時期に咲く」で絞り込み）から好きな植物を選べる。配置と株数は自動で直す。どのモードでも植物カードの「ほかの植物に替える」で差し替え可能 |
| 🎨 イメージ図の描き分け | 剣形の葉（アヤメ・ヘメロカリス・クニフォフィアのトーチ・クロコスミアの弓なりの花・アガパンサスの花火形）、大きな葉（ギボウシ・ツワブキ・リグラリア・アーティチョーク）、釣鐘（ジギタリス・カンパニュラ・オダマキ・アマドコロ・スズラン）、カップ（チューリップ・ポピー・シャクヤク）、ラッパ（ユリ・スイセン）、ヒガンバナ、オベリスクに絡むクレマチス、ロゼット（アロエ）、アジサイ（手まり・額・円錐）、バラを描き分け |
| 🩺 困ったとき（症状から調べる） | 「葉が黄色い」「白い粉」「穴」「しおれる」「花が咲かない」など17の症状を選ぶと、病害虫と育て方の問題（水切れ・過湿・葉焼け・日照不足・肥料・根詰まり・寒さ・蒸れ・剪定時期・株の老化・自然な休眠など）から原因を推定。植物・季節・地域・鉢か地植えか・植えてからの年数を考えて「可能性が高い／ありうる／念のため」に分け、確かめることと対処を表示。写真といっしょにAIに相談する文も作る |
| 💧 今日の水やり | ホームに、過去3日の雨と今日の気温から「地植え／鉢植え／植えたばかりの株」ごとの水やりの要否（不要・土を確かめて・朝に1回・朝夕2回）を表示 |
| ✅ 作業のチェックとカレンダー登録 | 作業暦の各作業に「やった」チェック（日付つき、ホームの今月の作業からも消える）。今後12か月の作業と庭づくりの段取りを、スマホのカレンダーに登録できる形式（.ics、各月の最初の土曜の朝9時に通知）で書き出し |
| 🪴 植物ごとの記録 | マイ庭の植物に「植えた日・場所・鉢植えかどうか・メモ（買ったお店など）」を記録。「植えた」にすると植えた日を自動で記録。水やりと診断に活用 |
| 🧮 庭仕事の計算機 | 苗の数（千鳥・ます目）、土づくり（耕す土と堆肥の量・袋数）、鉢の土（号数から容量・袋数・鉢底石）、肥料（元肥・追肥・置き肥・液肥の原液量）、マルチ（量・袋数） |
| 📑 目次 | 長いページの上に、折りたたみ式の「このページの目次」。タップで該当の場所へ移動 |
| 🔄 別の案 | 庭まるごとプランで「植栽だけ変える」「配置も変える」を選べる。配置の案では、小道の形（外周を回る・蛇行・十字）、左右の反転、テラスの位置、花壇の奥行き、パーゴラ・木・池の位置、島花壇の形が変わる |
| 🔎 生き物図鑑と観察記録 | 54種の生き物をイラスト付きの図鑑で表示（大きさ・見られる月・見分け方・似ている生き物・観察のコツ・食べもの・幼虫が育つ植物・呼びよせる植物）。種類・今月・この庭に来そう・見つけた/まだで絞り込み。「見た！」で日付・場所・数・メモを記録し、見つけた種類を集めていける |
| 🕸 生態系図 | 庭の植物と来そうな生き物から「食べる・食べられる」のつながり（植物がつくるもの→植物を食べる生き物→虫を食べる生き物→鳥・コウモリ）を図にして解説。マイ庭・花壇プラン・庭まるごとプランで表示 |
| 🐝 庭のお客さん | ツピの友だち（ミツバチのミッチ、テントウムシのテンテン、アマガエルのアマタ、カナヘビのカナ、ダンゴムシのコロン、メジロのメジロー）が、季節に合わせてホームにランダムで1〜3匹遊びに来て、庭の様子に合わせたひとことを話す。タップすると生き物図鑑へ |
| 🦋 生き物と生物多様性 | 蝶・蛾・蜂・甲虫・トンボ・バッタ・野鳥・カエル/トカゲなど約50種の生き物と、植物（幼虫の食草・蜜・実や種・すみか）や庭の環境（水場・池・木・堆肥置き場・石積み・冬の枯れ茎）との関係を収録。図鑑に「この植物に来る生き物」、マイ庭とプランに「来そうな生き物」と **生物多様性度（100点の目安：蜜源のリレー・植物の多様さ・高さの層・在来種・食べもの・すみか）** と改善のヒント、「楽しむ」に地域で月ごとに見られる生き物を表示。プラン作成時に「呼びたい生き物」を選ぶと、その食草や蜜源を優先 |
| 🪴 複数の庭 | 庭をいくつでも作成（名前・日当たり・土の湿り気・広さ・メモ）。庭ごとに植物リスト、「植えた／ほしい」の管理、買い物リスト（株数・概算・通販検索）。ホームや作業暦は選んだ庭に合わせて表示 |
| 📖 解説文 | 全品種に「特徴・育て方・手入れ・庭での使い方」の解説と、相性のよい植物を表示（登録データから自動で組み立て） |
| 🖼 写真 | 植物ごとに自分で撮った写真を設定可能。プランの絵は画像（PNG）として保存・共有できる |
| 🪴 マイガーデン | 選んだ植物の **開花リレー表**、花が途切れる月の検出とその月に咲くおすすめ植物、草丈による前景・中景・後景の配置と、花壇面積からの株数の目安 |
| 🎨 植栽スタイル | プラン作成時に選択：レイヤードボーダー（基本）／**ニューパレニアル**（ピート・アウドルフの手法を参考：グラスの地模様＋群植ブロック＋散らし、枯れ姿まで楽しむ）／**マトリクス植栽**（レイナー＆ウェスト：骨格・季節のテーマ・グラウンドカバーの3層を密に混植）／**カラーグラデーション・ボーダー**（ガートルード・ジーキル：両端寒色→中央暖色）／**グラベルガーデン**（ベス・チャトー：乾燥に強い植物と砂利）。スタイルごとに植物の選び方・配置アルゴリズム・資材費が変わる |

#### 一年草と薬用植物
- 一年草・二年草は冬の寒さの判定を行わず、地域の気候から種まき時期（暖地は秋まき、寒冷地は春まき）を案内。プランでは「一年草も使う」を選んだときだけ使用。
- 薬用植物（生薬・民間薬として知られる植物）にはタグと注意書きを表示。本アプリの情報は園芸・文化の紹介であり、医療上の助言ではありません。

### 判定の考え方
- **寒さ**：年最低気温の10年平均 → USDA ゾーン。年間降雪100cm以上の地域は雪の保温効果を考慮して1ゾーン分ゆるく判定。
- **暑さ**：30℃以上の日数 → AHS 暑さゾーン。植物ごとの上限と比較。
- **蒸れ**：熱帯夜（最低気温25℃以上）の日数から、日本の夏特有の「蒸れ」ストレスを評価。
- **霜**：最低気温0℃以下となる最終日・最初の日の中央値。植え付けの安全日は80パーセンタイル。
- 南半球の位置でも季節をずらして計算します。

## データ出典
- 気象：[Open-Meteo](https://open-meteo.com/) Historical Weather API（ERA5 再解析）・Forecast API（CC BY 4.0）
- 地名検索：Open-Meteo Geocoding API ／ 逆ジオコーディング：BigDataCloud
- 植物写真：Wikipedia / Wikimedia Commons（各画像のライセンスはリンク先を参照）。取得できない場合はイラストを表示
- 植物の耐寒・耐暑ゾーン、価格（9〜10.5cmポット苗の一般的な販売価格）などは目安です。

約10km格子の気象データのため、市街地のヒートアイランド、谷の冷気だまり、建物の陰など庭の微気候とは差が出ることがあります。
保存データ（場所・マイガーデン）は端末のブラウザ内にのみ保存されます。

## 料金について
このアプリは完全に無料です。APIキーの登録や課金の仕組みは一切なく、有料のサービスを呼び出しません。
アプリが通信するのは、無料で公開されている気象データ（Open-Meteo）、地名（BigDataCloud）、植物写真（Wikipedia / Wikimedia Commons）、フォント（Google Fonts）だけです。
「AIに相談」は相談文を作り、AIアプリを開くリンク（相談文はリンクの中に入れるだけ）とコピーを用意するだけで、AIのサービスへの送信は利用者自身が各AIアプリの無料の範囲で行います。
構造物の費用は材料費の目安を表示するだけで、購入や見積もり依頼などの通信は行いません。

## 申し送り（未対応）

- プラン結果の URL 共有：プランの入力をすべて URL に載せる必要があり、データ構造の変更が大きいため後回し。代わりに「印刷する」（A4想定）と「プランの概要をコピー」を用意した。
- 地名検索のひらがな入力（例「ちばけんあさひし」）：地名データベース（Open-Meteo）がかなでの検索に対応していないため未対応。漢字での「千葉県旭市」「千葉県 旭市」「旭市」には対応。
- 土の酸度（pH）：酸性・アルカリ性を好むことがはっきりしている植物から個別データを入れた。そのほかは「一般的な草花の目安・個別データは準備中」と明示している。
