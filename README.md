# 宿根草ガーデンナビ 🌼

位置情報から **あなたの庭の気候** を調べ、宿根草ガーデンづくりを手助けする Web アプリ（PWA）です。
インストール不要・APIキー不要で、スマホのブラウザからそのまま使えます。

## できること

| 画面 | 内容 |
| --- | --- |
| 🌍 場所と気候 | 現在地 or 地名検索 → 過去10年の気象データから **耐寒性ゾーン（USDA）・暑さゾーン（AHS）・終霜／初霜・熱帯夜・降水量・降雪量** を算出。地域ごとの栽培ポイント、月別の気温・降水グラフ、季節ごとの南中高度と「高さ2mの塀の影の長さ」も表示 |
| 🌼 図鑑 | **219種・638品種**（宿根草・グラス・ハーブ・小低木・シダ・植えっぱなし球根）。名前・学名・科で検索、科・種類・花期・花色・用途（ドライフラワー・種取り・ハーブティー・草木染め・冬の枯れ姿など）で絞り込み、並べ替え（科ごと・花期順・草丈順・価格順）、一覧／カード表示。各植物に科・用途・豆知識（名前の由来・逸話・受賞歴など）。品種ごとに花色・草丈・開花期・耐寒性・耐暑性・蒸れへの強さ・葉色・価格が異なる場合は個別に収録。種ごとのカードで品種を切り替えて比較できる。写真（品種名で Wikimedia Commons を検索、なければ種の Wikipedia 写真）、花色・草丈・開花期・花の形・葉色・株間・平均価格・雰囲気タグを掲載。日当たり・湿り気・草丈・花色・開花月・雰囲気で絞り込み、地域の気候に対して **◎ よく育つ / ○ 工夫すれば育つ / △ 難しい** を理由付きで判定 |

| 🪴 マイガーデン | 選んだ植物の **開花リレー表**、花が途切れる月の検出とその月に咲くおすすめ植物、草丈による前景・中景・後景の配置と、花壇面積からの株数の目安 |
| 🎨 植栽スタイル | プラン作成時に選択：レイヤードボーダー（基本）／**ニューパレニアル**（ピート・アウドルフの手法を参考：グラスの地模様＋群植ブロック＋散らし、枯れ姿まで楽しむ）／**マトリクス植栽**（レイナー＆ウェスト：骨格・季節のテーマ・グラウンドカバーの3層を密に混植）／**カラーグラデーション・ボーダー**（ガートルード・ジーキル：両端寒色→中央暖色）／**グラベルガーデン**（ベス・チャトー：乾燥に強い植物と砂利）。スタイルごとに植物の選び方・配置アルゴリズム・資材費が変わる |
| 🦠 病害虫 | 気候データから地域で起きやすい病害虫（うどんこ病・白絹病・灰色かび病・蒸れ・ナメクジ・ハダニ等）を推定し、予防と対処を表示。植物カードにも注意点、作業暦に予防・見回りの時期を追加 |
| 🔰 はじめてガイド | 場所設定→日当たり観察→水はけ確認→土づくり→苗選び→植え付け→マルチング→水やり…を地域の気候に合わせた内容で案内するチェックリスト |
| ＋ 品種登録 | 園芸店で見つけた品種を自分で登録（花色・草丈・開花月・価格・購入店・商品URL）。登録した品種も判定・プラン・作業暦に反映。各植物から通販サイトで検索（楽天市場／Yahoo!ショッピング／Amazon／Google） |
| 🍂 楽しむ | 今月の庭の楽しみ（霜の朝の枯れ姿、十五夜の七草、逆光のグラス…）と、自然派の暮らしのレシピ（ドライフラワー、種取りと冬まき、ハーブティー、ポプリ、押し花、草木染め、リース、堆肥、焚き火と草木灰、庭の山菜）。あなたの庭の植物で何ができるかを表示。今日の豆知識 |
| 📔 庭ノート | 写真付きで開花や作業を記録（端末内の IndexedDB に保存） |
| 💾 データ保存 | 永続保存の要求、全データ（庭ノートの写真を含む）のバックアップ／復元。iPhone は共有メニューから iCloud Drive に保存可能 |
| ☁️ 今週の天気 | 7日間の予報から霜・猛暑・大雨・強風・長雨の注意や「庭仕事日和」を作業暦に表示 |

### 判定の考え方
- **寒さ**：年最低気温の10年平均 → USDA ゾーン。年間降雪100cm以上の地域は雪の保温効果を考慮して1ゾーン分ゆるく判定。
- **暑さ**：30℃以上の日数 → AHS 暑さゾーン。植物ごとの上限と比較。
- **蒸れ**：熱帯夜（最低気温25℃以上）の日数から、日本の夏特有の「蒸れ」ストレスを評価。
- **霜**：最低気温0℃以下となる最終日・最初の日の中央値。植え付けの安全日は80パーセンタイル。
- 南半球の位置でも季節をずらして計算します。

## 使い方（ローカル）

位置情報 API は HTTPS または `localhost` でのみ動作します。

```bash
npm start        # = python3 -m http.server 8080
# → http://localhost:8080 を開く
npm test         # 解析ロジックのテスト（Node.js 18+）
```

GitHub Pages などの静的ホスティングに置けばスマホから使え、ホーム画面に追加するとアプリのように起動します。

## データ出典
- 気象：[Open-Meteo](https://open-meteo.com/) Historical Weather API（ERA5 再解析）・Forecast API（CC BY 4.0）
- 地名検索：Open-Meteo Geocoding API ／ 逆ジオコーディング：BigDataCloud
- 植物写真：Wikipedia / Wikimedia Commons（各画像のライセンスはリンク先を参照）。取得できない場合はイラストを表示
- 植物の耐寒・耐暑ゾーン、価格（9〜10.5cmポット苗の一般的な販売価格）などは目安です。

約10km格子の気象データのため、市街地のヒートアイランド、谷の冷気だまり、建物の陰など庭の微気候とは差が出ることがあります。
保存データ（場所・マイガーデン）は端末のブラウザ内にのみ保存されます。
