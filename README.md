# 宿根草ガーデンナビ 🌼

位置情報から **あなたの庭の気候** を調べ、宿根草ガーデンづくりを手助けする Web アプリ（PWA）です。
インストール不要・APIキー不要で、スマホのブラウザからそのまま使えます。

## できること

| 画面 | 内容 |
| --- | --- |
| 🌍 場所と気候 | 現在地 or 地名検索 → 過去10年の気象データから **耐寒性ゾーン（USDA）・暑さゾーン（AHS）・終霜／初霜・熱帯夜・降水量・降雪量** を算出。地域ごとの栽培ポイント、月別の気温・降水グラフ、季節ごとの南中高度と「高さ2mの塀の影の長さ」も表示 |
| 🌼 植物を探す | 約70種の宿根草データベースから、日当たり・土の湿り気・草丈・花色・開花月で絞り込み。地域の気候に対して **◎ よく育つ / ○ 工夫すれば育つ / △ 難しい** を理由付きで判定 |
| 🪴 マイガーデン | 選んだ植物の **開花リレー表**、花が途切れる月の検出とその月に咲くおすすめ植物、草丈による前景・中景・後景の配置と、花壇面積からの株数の目安 |
| 📅 作業暦 | その土地の霜の時期・暑さ・蒸れやすさ、マイガーデンの植物に合わせた **月ごとの作業**（植え付け・株分け・チェルシーチョップ・梅雨前の透かし・冬支度など）。今月見頃の植物も表示 |

### 判定の考え方
- **寒さ**：年最低気温の10年平均 → USDA ゾーン。年間降雪100cm以上の地域は雪の保温効果を考慮して1ゾーン分ゆるく判定。
- **暑さ**：30℃以上の日数 → AHS 暑さゾーン。植物ごとの上限と比較。
- **蒸れ**：熱帯夜（最低気温25℃以上）の日数から、日本の夏特有の「蒸れ」ストレスを評価。
- **霜**：最低気温0℃以下となる最終日・最初の日の中央値。植え付けの安全日は80パーセンタイル。
- 南半球の位置でも季節をずらして計算します。

## 使い方（ローカル）

位置情報 API は HTTPS または `localhost` でのみ動作します。

```bash
npm start        # = python3 -m http.server 8080
# → http://localhost:8080 を開く
npm test         # 解析ロジックのテスト（Node.js 18+）
```

GitHub Pages などの静的ホスティングに置けばスマホから使え、ホーム画面に追加するとアプリのように起動します。

## 構成

```
index.html            画面
css/style.css         スタイル（ライト／ダーク対応）
js/app.js             画面の制御・グラフ描画
js/climate.js         気象データ取得と解析（ゾーン・霜・暑さ）
js/garden.js          適性判定・開花リレー・作業カレンダー生成
js/sun.js             太陽高度・日長・影の計算
js/plants.js          宿根草データベース
sw.js / manifest      PWA（オフライン起動）
tests/                ロジックのテスト
```

## データ出典
- 気象：[Open-Meteo](https://open-meteo.com/) Historical Weather API（ERA5 再解析、CC BY 4.0）
- 地名検索：Open-Meteo Geocoding API ／ 逆ジオコーディング：BigDataCloud
- 植物の耐寒・耐暑ゾーンなどは一般的な園芸資料をもとにした目安です。

約10km格子の気象データのため、市街地のヒートアイランド、谷の冷気だまり、建物の陰など庭の微気候とは差が出ることがあります。
保存データ（場所・マイガーデン）は端末のブラウザ内にのみ保存されます。
